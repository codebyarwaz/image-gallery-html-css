# Image Gallery Website

A simple and responsive Image Gallery website built using HTML and CSS. This project showcases images in a clean and attractive layout using CSS Grid and Flexbox.

## Features

- Responsive Image Gallery Layout
- CSS Grid and Flexbox
- Attractive Hover Effects
- Image Captions
- Clean and Simple UI
- Beginner-Friendly Project

## Technologies Used

- HTML5
- CSS3
